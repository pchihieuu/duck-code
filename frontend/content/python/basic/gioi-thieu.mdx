# Giới thiệu Python

<Note>
Python là ngôn ngữ lập trình bậc cao, cú pháp gần với ngôn ngữ tự nhiên,
phù hợp cho người mới bắt đầu.
</Note>

## Vì sao học Python?

- Cú pháp đơn giản, dễ đọc
- Cộng đồng lớn, nhiều thư viện
- Ứng dụng rộng: web, data, AI, tự động hoá

<Tip>
Hãy gõ lại từng ví dụ thay vì chỉ đọc — việc này giúp ghi nhớ cú pháp nhanh hơn.
</Tip>

## Ví dụ đầu tiên

```python
print("Xin chào, Python!")
```

<Warning>
Python phân biệt chữ hoa/thường và dùng thụt lề (indentation) để xác định khối lệnh —
thụt lề sai sẽ gây lỗi cú pháp.
</Warning>
